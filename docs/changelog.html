Changelog

What’s new.

Every release, from the first build to today. Version 0.0.8 is the latest.

Update in VS Code All releases on GitHub
0.0.8
September 17, 2026 Latest

Accessibility and reliability

Keyboard reordering for KeyIdentifiers and a sturdier whole-file panel.

Added

  • Accessible names on whole-file field checkboxes, taken from each field’s path and name.
  • Keyboard Move up / Move down controls for reordering KeyIdentifiers in Settings, alongside drag and drop.

Fixed

  • Whole-file panel ignores stale renders after handing the webview to the main AES screen.
  • Whole-file panel tags each field refresh with its operation and request, drops stale Encrypt/Decrypt toggles, and keeps Apply disabled until the matching refresh arrives.
0.0.7
September 16, 2026

Quoted values and a simpler file workflow

Decrypt now understands the quotes YAML needs, and selection is one checkbox away.

Added

  • Quoted secure-value detection for decrypt ("![…]" and '![…]') in YAML and properties files.
  • An AES Encrypt / Decrypt logo button on the whole-file panel that opens the main AES screen.

Changed

  • The whole-file panel replaces Select all, Clear and Refresh with a single master checkbox (nothing selected by default). Decrypt mode now uses the same per-field selection as encrypt.
  • Both editor toolbar buttons are back for YAML and properties files: aes.encryptDecrypt and aes.fileEncryptDecrypt.
  • Removed automatic clipboard prefill from the main AES panel.
0.0.6
July 10, 2026

Reorder keys, open beside the editor

Put your KeyIdentifiers in the order you use them, and keep your file in view.

Added

  • Drag-to-reorder KeyIdentifiers in Settings. The saved order is used by every KeyIdentifier dropdown.
  • An editor toolbar button for the main AES screen on .yaml, .yml and .properties files, next to the whole-file button.
  • The AES panel opens beside the editor, and fills an empty Input Text from the clipboard.
  • An Open in sidebar button on the whole-file panel that reveals the MuleSoft AES view.
  • A new toolbar icon so the two editor buttons are easy to tell apart.
0.0.5
June 11, 2026

Inline and whole-file encryption

The extension moves into the editor.

Added

  • Whole-file workflow (MuleSoft AES: Encrypt / Decrypt File): scan the active YAML or properties file, pick the values to encrypt, and apply them in one edit. Each row shows name, value, path and line number.
  • Inline selection actions: Encrypt Selection and Decrypt Selection in the editor context menu, using a saved KeyIdentifier or a one-off key.
  • An editor toolbar button for the whole-file workflow.
  • A compact editor-crypto mode in the sidebar.
  • Test coverage for field scanning and transforms.
0.0.4
June 9, 2026

Save keys from the encrypt screen

Added

  • Typing a custom key on the AES or Secure Properties screen reveals a save button. Name it, and it’s stored as a KeyIdentifier and available on both screens immediately.

Changed

  • Reworked the publish workflow and consolidated publishing notes into the README.
0.0.3
June 3, 2026

The Secure Properties tool

Multi-algorithm support with full generator parity.

Added

  • MuleSoft Secure Properties Encrypt / Decrypt: AES, Blowfish, DES, DESede, RC2 and RCA; CBC, CFB, ECB and OFB; and optional random IVs. At its defaults it matches the AES tool byte for byte.
  • Adaptive controls: Use Random IVs disables for ECB, and both mode and IV disable for RCA.
  • Test coverage for the new cipher logic.

Changed

  • The new tool shares KeyIdentifier storage and the sidebar with the AES tool.
  • Fixed the Base64 tool’s icon background.
0.0.1
June 2, 2026 First release

Hello, MuleSoft AES

Added

  • MuleSoft AES Encrypt / Decrypt: AES-128-CBC or AES-256-CBC by key length, PKCS5 padding, and an IV derived from the key, in MuleSoft’s ![base64] format.
  • Base64 Encode / Decode for text and files, with drag and drop and clipboard copy.
  • Settings for KeyIdentifiers: DEV, FIT, UAT and PROD presets plus custom keys, stored in VS Code’s secret storage with masking.
  • The MuleSoft AES activity-bar sidebar.
