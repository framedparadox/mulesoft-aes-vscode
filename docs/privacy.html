Privacy

Nothing to collect. Nothing collected.

This policy covers the MuleSoft AES & Secure Properties extension for VS Code and this website. Effective September 28, 2026.

In short

  • The extension makes no network requests and collects no telemetry.
  • Your keys stay in your operating system’s credential store, on your machine.
  • This website sets no cookies, runs no analytics, and loads nothing from third parties.

The extension

What it stores

KeyIdentifier names and their encryption keys are saved in VS Code’s SecretStorage, which is backed by your operating system’s credential vault: macOS Keychain, Windows Credential Manager, or Secret Service / pass on Linux. They are never written to settings.json, to your workspace, or to any file the extension creates.

Keys you type with Input key manually or as a one-off custom key are used for that operation only and are not stored unless you choose to save them.

What it sends

Nothing. All encryption, decryption and Base64 conversion runs locally, in-process, using the Node.js and OpenSSL runtime that ships with VS Code. The extension makes no network requests, calls no external APIs, and includes no analytics or telemetry of its own.

What it changes

It edits files only when you ask it to: replacing a selection, or applying the fields you tick in the whole-file workflow, as a normal, undoable VS Code edit.

Marketplaces

When you install or update the extension, you interact with the VS Code Marketplace, Open VSX or GitHub, each under its own privacy terms. VS Code’s own telemetry settings are controlled by VS Code, not by this extension.

This website

  • No cookies, no analytics, no trackers. The site loads no third-party scripts, fonts, images or embeds.
  • Local preference only. If you choose Light or Dark appearance, that choice is saved in your browser’s local storage so it’s remembered next time. It never leaves your device, and you can clear it by choosing Auto or clearing site data.
  • The live demo stays in your browser. It uses the Web Crypto API on your device. Keys and text you type are not transmitted or stored.
  • Hosting. Like any website, the host that serves these pages may keep standard server logs (such as IP address and user agent) under its own policies.

Even though the demo runs locally, please don’t paste production keys or secrets into any website. Use the extension for real work.

Changes and contact

If this policy changes, the updated version will be published on this page with a new effective date, and noted in the changelog where it affects the extension.

Questions? Open an issue on GitHub. The source code for both the extension and this website is public, so you can verify everything above.
